# Security Policy

This repository is an educational portfolio project. Do not submit real alerts, credentials, internal indicators, customer data, or other sensitive information to the public demo or issue tracker.

If you identify a security issue in the code, report it privately to the repository owner through the contact method listed on the portfolio. Do not include live credentials or production evidence.

The sample domains and IP addresses are documentation-only values. Production use requires security review, access control, audit logging, secret management, error handling, API throttling, and formal approval for any automated response action.
