Microsoft Sentinel Home SOC Lab

A practical Azure security monitoring lab focused on telemetry onboarding, KQL investigation, analytics-rule concepts, incidents, entities and threat hunting.

Microsoft SentinelLog AnalyticsKQLAMADCRDefender

Lab Objective

Build the core workflow of a small SOC: collect security telemetry, investigate events, create detections, correlate entities and document analyst decisions.

Environment

Azure resources, Windows virtual machines, Log Analytics Workspace and Microsoft Sentinel used as a safe learning environment for security operations.

Detection-to-Response Flow

1
TelemetryWindows, Azure and identity-related events are collected through supported connectors and agents.
2
Log AnalyticsEvents land in workspace tables where they can be queried and correlated.
3
KQL investigationFilter time windows, users, hosts, processes, IPs and authentication activity to validate suspicious behavior.
4
DetectionUse analytics-rule concepts to identify patterns that should produce alerts.
5
Incident triageReview alerts, entities, evidence, severity and related activity before escalation or closure.
6
Hunting & improvementUse lessons from incidents to refine queries, detections and investigation playbooks.

  • AMA / DCR concepts

  • Alert and incident investigation
